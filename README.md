# CDP Domain 1 Quiz — GitHub Pages

A static HTML/CSS/JavaScript version of the uploaded Tkinter quiz. It preserves the first 100 entries returned by the original `build_question_bank()` function, including each topic, question, four options, keyed correct-answer index, and explanation.

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `questions.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for the deployment and open the URL shown on the Pages settings screen.

No Python server, build step, or third-party JavaScript library is required. Internet is only used optionally for the Google Fonts stylesheet; the quiz itself runs locally in the browser.
